# Zone Distribution Dashboard

A production-ready static GitHub Pages dashboard generated from one Excel workbook.

## Designed from the supplied workbook

The package detects the current source by its **26-column schema**, not by the Excel filename or worksheet name. The current workbook contains the dashboard source table with 26 required headers.

## Dashboard features

- Responsive KPI cards for visible outlets, SFT, PNP/Non-PNP, OWN/FR and district coverage
- Filters for Regional Head, Zonal HR, Division, District, Format, PNP status, Outlet Status and advanced location attributes
- Global search across all 26 source columns
- Dynamic charts that recalculate after filters
- **Sorting on every column**
- Correct numeric/date/text sorting
- 25 / 50 / 100 / 250 / All row page sizes
- Column chooser plus a compact Core View
- Frozen SL, CODE and Outlet Name columns during horizontal scrolling
- Clickable Google Maps links
- Download filtered data as CSV
- Input schema validation with clear build errors
- Duplicate/blank outlet-code quality indicator
- No external Python package dependency for the build
- GitHub Actions → GitHub Pages automatic deployment

## Input replacement rule

The workbook filename can change freely.

Examples that all work:

- `Zone Distribution Aug 2026.xlsx`
- `Latest Outlet Master.xlsx`
- `Network Location Data 15 Aug.xlsx`

The build script scans `/data/*.xlsx` and detects the worksheet from the required header schema.

See `data/README.md` for the exact required headers.

## Local build

```bash
python scripts/build.py
```

Then serve `site/` through any static HTTP server, for example:

```bash
python -m http.server 8000 -d site
```

Open `http://localhost:8000`.
